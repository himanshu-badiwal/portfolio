# Himanshu Badiwal - Professional Portfolio Website

A modern, responsive, high-converting single-page portfolio website for **Himanshu Badiwal** — Digital Marketing Executive, Social Media Manager, and Content Creator.

## 🚀 Live Preview & Running Locally

This is a clean, static, zero-build website powered by:
- **HTML5 & Modern CSS3**
- **Tailwind CSS** (via CDN with custom color tokens and animations)
- **Lucide Icons**
- **Google Fonts** (Outfit & Plus Jakarta Sans)
- **Vanilla JavaScript** (dynamic scroll progress, mobile drawer menu, copy-to-clipboard, interactive contact form)

### How to View:
Simply double-click or open [index.html](file:///d:/Work/portfolios/portfolio/index.html) in any modern web browser (Google Chrome, Edge, Safari, Brave, Firefox), or serve it with any static server:

```bash
# Using VS Code Live Server, or Python:
python -m http.server 8000
```
Then visit `http://localhost:8000`.
